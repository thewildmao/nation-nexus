# js/ui

Shared DOM. Safe to import from shell and games. Do not award points here.

| File | Role |
|---|---|
| `overlay.js` | Open / leave / `prefers-reduced-motion` timing |
| `dialog.js` | Confirm overlay |
| `settings.js` | Settings overlay |
| `filter-tree.js` | Region set picker (home board + overlay) |
| `score-dock.js` | Points, streak, combo shout |
| `screens.js` | Which pane is visible; reparents compact set chip + dock |
| `identity.js` | Names, logos, lockups |
| `game-card.js` | Home cards from `PLAY_MODES` |
| `country-map.js` | Locator map (study + quiz) |
| `outlines.js` | GeoJSON fetch for both Leaflet maps |
| `nav.js` | Hash routes |
| `dom.js` | Host lookups for markup still in `index.html` |
| `sfx.js` / `timer.js` | Sound and play clock |
