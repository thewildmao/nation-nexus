# Flag Master + Capital Quest

One quiz engine, two identities.

| File | Role |
|---|---|
| `rules.js` | Deal a country, grade multiple choice or type-in. No DOM. |
| `view.js` | Prompt, options, type-in, locator map |
| `session.js` | Start round, submit, next, answer-style change |

Which game it is comes from `state.mode` (`flags` or `capitals`). Titles and blurbs live in `js/ui/identity.js`.
